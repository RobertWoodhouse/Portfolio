C# Unity3D Android Mobile Game

I'll Name This
Game Later

A retro-styled Android shoot 'em up inspired by Asteroids and Defender. Survive as long as you can in deep space. The longer you last, the harder it gets.

Overview

I'll Name This Game Later is a classic top-down shoot 'em up for Android, built in Unity with C#. The goal is simple: survive deep space as long as possible against an ever-increasing wave of obstacles and enemies. It draws heavily from the arcade era: the look, the feel, the punishing difficulty.

The dynamic soundtrack was one of the more interesting engineering challenges. The music system monitors player performance in real-time and adjusts intensity accordingly. A good run feels cinematic, a scrappy one feels tense.

Key Features

  • Standard shooter and charged-shot weapons
  • 3 unlockable ships, each with unique speed, damage, and a fully voiced ship computer
  • Dynamic soundtrack that scales with player skill
  • Randomly generated obstacles with increasing difficulty over time
  • Top 10 leaderboard

What I Learned

This was my first full mobile release. Getting the game onto the Play Store taught me as much about product, things like store listings, screenshots, and release pipelines, as it did about Unity. The dynamic audio system was the most technically interesting piece, requiring continuous state polling and smooth track blending.
